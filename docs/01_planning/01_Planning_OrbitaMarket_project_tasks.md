# Планирование задач проекта OrbitaMarket

## Назначение раздела

Раздел «Планирование задач» описывает, как будет организована разработка платформы OrbitaMarket - системы для оформления заказов на спутниковые продукты и списания оплаты в геокредитах.

Планирование включает:

- цель проекта;
- заинтересованные стороны;
- границы MVP;
- этапы разработки;
- roadmap с датами;
- список задач по каждому сервису;
- ожидаемые HTTP-запросы и ответы;
- события асинхронного взаимодействия;
- оставшиеся пункты работы;
- план доработки графического интерфейса.
