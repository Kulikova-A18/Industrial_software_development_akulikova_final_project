# Планируемые статусы заказа

| Статус          | Когда устанавливается                    |
| :-------------- | :--------------------------------------- |
| CREATED         | Заказ создан в базе до отправки события  |
| PAYMENT_PENDING | Событие на оплату создано или отправлено |
| PAID            | Payments успешно списал геокредиты       |
| PAYMENT_FAILED  | Payments не смог списать средства        |
| REJECTED        | Заказ отклонен из-за невалидных данных   |
