# План реализации графического интерфейса

Графический интерфейс планируется реализовать после завершения серверной части MVP. Frontend будет работать через API Gateway, не обращаясь напрямую к Orders Service и Payments Service.

> **Важно!** Данная реализация не обязательна.

## Цель графического интерфейса

Цель GUI - предоставить пользователю удобный способ взаимодействия с платформой OrbitaMarket без использования Postman или curl.

Пользователь сможет:

- указать X-User-Id;
- создать счет;
- пополнить баланс;
- посмотреть баланс;
- создать заказ;
- посмотреть список заказов;
- открыть карточку заказа;
- увидеть статус оплаты;
- повторно обновлять статус заказа через polling.
